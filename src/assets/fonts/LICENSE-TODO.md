# Font licensing — action required before sale or distribution

`ClarizaSparks-Regular.woff`/`.woff2` is the theme's signature display/heading
font (`src/styles/global.css`). No license file or purchase record exists in
this repo for it.

**Before this theme is sold or distributed, confirm:**

- Where this font came from and whether the license covers embedding in a
  product that is redistributed to third parties (most retail font EULAs
  license _use on your own sites_, not _bundling into a theme others download
  and deploy on their own domains_).
- If it's a webfont-license purchase, whether it covers unlimited page views /
  domains, since buyers will each deploy it to their own domain.

If the license doesn't cover redistribution, replace the display/heading role
with an open-license alternative (Syne, Archivo Black, and Space Grotesk are
close visual matches and are all SIL Open Font License).

58 other unlicensed, unused font files were removed from this directory on
2026-09-05 (RUBRIC.md remediation, P0-1) — they were dead weight regardless of
license status. This is the one remaining file that's actually load-bearing.
