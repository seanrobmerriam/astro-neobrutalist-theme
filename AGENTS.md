# Astro Neubrutalist Theme

You are building a complete Astro neubrutalist theme with tailwindcss. Complete means that a user can install it, and use it to build a variety of sites or applications with it.

It should be composed of:

- Multiple *pages* to serve as examples e.g. home, about, contact, FAQ, features.
- Multiple *layouts* e.g. a main layout, a (logged in) user layout, an application layout, etc.
- Multiple *blocks* of individual components.
- Multiple individual components. It should include every type of basic component, which should then be used to build blocks. Blocks should then be used to build layouts and pages.

# Components

## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.
